Sprout privacy policy

Keyword expander for Amazon sellers. Not affiliated with Amazon. Last updated 21 November 2026.

Sprout is a free browser extension. It has no accounts, no ads, no analytics, and no server of its own. The developer does not receive the keywords you type.

What stays on this device

The seed, marketplace choices, department, expansion options, excluded words, search-term settings, starred keywords, the last 20 runs, and the latest result list are stored in chrome.storage.local on that browser profile. A one-time “rate Sprout” note, once dismissed, is also stored there so it is not shown again. Uninstalling the extension removes this data. There is no account and no sync.

Amazon result counts from a session stay in the open panel until you close it. They are labeled as result counts, not search volume, and they are not sent to the developer.

What is sent, and where

When you press Expand, Sprout requests public Amazon autocomplete from this browser. The query is the seed plus a letter, digit, or connector word. Requests go to:

  • https://completion.amazon.<marketplace>/api/2017/suggestions
  • and, only if that host fails or does not return suggestion JSON, https://www.amazon.<marketplace>/suggestions

Those autocomplete requests do not attach cookies (credentials: "omit"). No other company receives the keyword from Sprout.

Two further Amazon page reads happen only when you ask, still in this browser:

  • Amazon result count. Results fetches https://www.amazon.<marketplace>/s?k=… for checked rows, or starred rows when none are checked, about one page per second. Cookies are omitted. Sprout reads the result-count line. The panel calls it a result count, not search volume. If the page is a robot check, counting stops.
  • Related searches. On an Amazon page the panel reads the related-search block already in the page. One more level fetches up to three of those search pages from this browser. The page’s own request context is used, so Amazon cookies already in the browser may be included. Product titles and “Visit the … Store” names are read from the page you are on. They become buttons. Nothing is excluded until you click.

Sprout does not read orders, reviews, payments, or your Amazon account. It does not request or store search volume, cost per click, or sales. It has no source for those numbers.

If you click Amazon, Google, or Trends on a keyword, the browser opens that site with the keyword in the link. That visit is between you and that site. Sprout does not observe it.

Translate, when you press it, uses Chrome’s on-device Translator if the browser provides it. Sprout does not send the seed to a translation service. If the API is missing, the translated field is only what you type.

What the on-page panel reads

On Amazon storefront pages where the panel is injected, Sprout reads the current URL, the search box, the department menu (#searchDropdownBox), the product title when that element is on the page, related-search links, and visible store or brand lines such as “Visit the … Store”. Those strings stay in the panel unless you choose to expand a term, which then uses the autocomplete requests above.

Permissions

  • storage — remember the last run and the dismissed rating note on this device.
  • sidePanel — open the research panel beside the page.
  • Host access to completion.amazon.* and www.amazon.* for the marketplaces in the selector only — call the suggestion endpoints, show the panel on those storefronts, and, only when you ask, fetch a search results page to read a result count or a related-search block.

Sprout does not request access to every website, to Seller Central, or to any host that is not an Amazon storefront or Amazon’s public suggestion host. The on-page script is the extension’s own code. Chrome lists it as a web-accessible resource limited to those Amazon storefronts so the page can load the panel.
